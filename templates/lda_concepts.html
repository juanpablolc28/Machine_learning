Linear Discriminant Analysis (LDA): Concepts

Theoretical foundation of the assigned classification algorithm for this group.

Name and Definition
Linear Discriminant Analysis (LDA) is a supervised classification algorithm that finds the linear combination of independent variables that best separates two or more classes, by maximizing the distance between class means while minimizing the variance within each class.
How It Works
LDA assumes that each class follows a normal (Gaussian) distribution with a shared covariance matrix across classes. It computes a linear "discriminant function" that projects the independent variables onto a new axis where the classes are as separated as possible, and then classifies new observations according to which class mean they are closest to on that axis.
Types of Problems It Solves
LDA is used for classification problems (binary or multi-class) where the goal is to assign an observation to one of several predefined categories using two or more numeric independent variables. It is also commonly used for dimensionality reduction prior to classification.
Main Characteristics
It is a linear model, it uses class-conditional Gaussian assumptions, it estimates class probabilities, and it can naturally handle more than two independent variables and more than two classes at once.
Advantages
LDA is computationally efficient, works well with a moderate number of features, tends to perform well when classes are approximately normally distributed and well separated, and provides interpretable, probability-based results.
Limitations
Its linear decision boundary struggles with classes that are not linearly separable, its performance degrades if the normality or equal-covariance assumptions are strongly violated, and it can be sensitive to outliers.
Real-World Example
Predicting whether a sports team will win a match based on several performance indicators collected during the game, such as possession percentage, shots on target, average goals scored, and whether the team played at home. LDA combines all of these variables into a single discriminant score used to classify the match outcome.
Applied Example

In this application, LDA is used to classify a match as a Win or Loss/Draw using four independent variables together: possession percentage, shots on target, average goals scored, and home advantage. Unlike the single-variable Logistic Regression model, LDA combines multiple performance indicators to make a more informed classification.
