Logistic Regression: Concepts

The theoretical foundation behind Binary Logistic Regression, before seeing it applied to a real classification problem.

What is Logistic Regression?
Logistic Regression is a supervised Machine Learning algorithm used to estimate the probability that an observation belongs to a specific category, based on one or more independent variables. Instead of fitting a straight line like Linear Regression, it fits an S-shaped curve (the sigmoid function) that maps any input to a value between 0 and 1.
Why Is It a Classification Algorithm?
Even though it is called "regression," its output is a probability that is then converted into a discrete class using a threshold. Because the final result is a category (not a continuous number), it is used to solve classification problems.
Binary Classification
Binary classification is a task where the target variable can only take one of two possible values or classes. Logistic Regression in its simplest form is designed specifically to solve this type of problem.
Independent Variable (X)
The input variable(s) used by the model to estimate the probability of belonging to a class. In this application, the independent variable is the team's ball possession percentage during the match.
Dependent / Target Variable (y)
The variable the model tries to predict. It is categorical, not numeric, and represents the outcome the model classifies observations into.
Classes or Labels
The two possible outcomes of the target variable. In this application: 0 = Loss / Draw and 1 = Win.
Probability of Belonging to a Class
For every new observation, the model computes a value between 0 and 1 that represents how likely it is that the observation belongs to class 1. A value of 0.83, for example, means an 83% estimated chance of winning.
Classification Threshold
The cutoff point (commonly 0.5) used to convert a probability into a class. If the estimated probability is greater than or equal to the threshold, the observation is classified as class 1; otherwise, as class 0.
Linear Regression vs. Logistic Regression
Linear Regression predicts a continuous numeric value and fits a straight line to the data. Logistic Regression predicts the probability of a categorical outcome and fits an S-shaped (sigmoid) curve, always producing a result between 0 and 1 that is later mapped to a discrete class.
Applied Example

In this application, Logistic Regression is used to estimate whether a team will win a match based on its ball possession percentage. The target variable has two classes: 0 = Loss / Draw and 1 = Win. The model is trained on historical match data and, once trained, can classify new matches it has never seen before.
