K-Means Clustering: Concepts

Theoretical foundation of the assigned unsupervised learning algorithm for this group.

Name and Definition
K-Means is an unsupervised clustering algorithm that partitions a set of observations into k groups (clusters), assigning each observation to the cluster whose centroid (mean) is closest to it.
How It Works
The algorithm starts by placing k initial centroids, then repeats two steps until convergence: (1) assign each record to the nearest centroid using Euclidean distance, and (2) recompute each centroid as the mean of the records assigned to it. This iterative process minimizes the within-cluster variance.
Types of Problems It Solves
K-Means is used for exploratory grouping problems where there is no predefined target/label, such as customer segmentation, document grouping, image compression, and, in this project, grouping football matches by performance profile.
Main Characteristics
It is an unsupervised, iterative, distance-based algorithm. The number of clusters (k) must be chosen beforehand, and numeric features are typically standardized before training so that no single variable dominates the distance calculation.
Advantages
K-Means is simple to understand, computationally efficient even on large datasets, and scales well. It works particularly well when clusters are roughly spherical and similarly sized.
Limitations
The number of clusters k must be chosen in advance, results depend on the initial centroid positions, it assumes roughly spherical clusters of similar size, and it is sensitive to outliers and to unscaled features.
Real-World Example
Grouping football matches into performance tiers (e.g., low, moderate, and high) based on possession, shots on target, average goals scored, average goals conceded, and home advantage, without knowing beforehand which matches belong to which tier.
Applied Example

In this application, K-Means (k = 3) is used to group football matches into performance tiers using five variables together: possession percentage, shots on target, average goals scored, average goals conceded, and home advantage. Unlike the classification models in the Supervised section, K-Means does not use the match result as a label — it discovers the grouping structure directly from the performance statistics.
