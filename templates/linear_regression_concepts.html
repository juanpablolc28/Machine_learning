Linear Regression: Concepts

The theoretical foundation behind Simple Linear Regression, before seeing it applied to a real prediction problem.

What is Linear Regression?
Linear Regression is a supervised Machine Learning algorithm used to model the relationship between two quantitative variables by fitting a straight line to a set of data points.
What Problems Can It Solve?
It is used to predict a continuous numeric value, such as a price, a quantity, or a consumption level, based on the value of another related variable.
Independent Variable (X)
The input variable used to make a prediction. It is the value the user provides to the model.
Dependent Variable (Y)
The variable the model attempts to predict. Its value depends on the independent variable.
Relationship Between Variables
Linear Regression assumes that as the independent variable changes, the dependent variable changes proportionally, following a straight-line pattern.
Regression Line
The straight line that best fits the training data, calculated by minimizing the distance between the predicted values and the real observed values.
Prediction
Once the model has been trained on historical data, it can estimate a Y value for any new X value using the equation of the regression line, even for values it has never seen before.
A Simple Example

Imagine a vehicle that consumes gasoline at a fairly constant rate. If we know how many liters it uses for different distances traveled, we can train a Linear Regression model where the independent variable is the distance in kilometers, and the dependent variable is the liters of gasoline consumed. Once trained, the model can predict the estimated gasoline consumption for any new distance, even one that was not part of the original data.
