Reinforcement Learning: Concepts

Theoretical foundation of Reinforcement Learning, explained using this project's own environment: a virtual agent navigating a 10×10 maze to reach a target while avoiding walls and danger zones.

What is Reinforcement Learning? It is a type of machine learning in which an agent learns to make decisions by interacting with an environment: it takes actions, observes what happens, and receives rewards or penalties. Over many attempts, it learns a policy — a strategy for choosing actions — that maximizes the total reward it can expect to collect, without ever being told the correct move in advance.

Core Building Blocks

🤖Agent
The decision-maker. In this project, the agent is the virtual robot moving through the maze, one cell at a time.
🗺️Environment
Everything the agent interacts with. Here, it is the 10×10 grid, together with its walls, danger zones, and movement rules.
📍State
A snapshot of the situation the agent is in. In this maze, the state is simply the agent's current (row, column) position.
🎮Action
A choice the agent can make in a given state. In this environment there are exactly four possible actions.

Feedback Signals

🏆Reward
A numeric signal telling the agent how good an outcome was. Reaching the target gives a large positive reward.
⚠️Penalty
A negative reward that discourages an action. Hitting a wall, leaving the grid, or entering a danger zone are all penalized.
📜Policy
The strategy the agent follows to pick actions from each state. Training gradually improves this policy.
👣Step
One state → action → reward → next state transition. An episode is made of many steps.

Learning Process

One full attempt at the maze: from the agent's start cell until it either reaches the target or runs out of allowed steps.

A single recorded transition (state, action, reward, next state) that the agent uses to update what it knows.

Trying random actions to discover parts of the maze the agent hasn't learned about yet, even if they seem suboptimal right now.

Choosing the action the agent currently believes is best, based on what it has learned so far.

With probability ε (epsilon) the agent explores (random action); otherwise it exploits (best known action). ε starts high and decays over training, so the agent explores a lot early on and relies more on its learned policy later.

The reward received right after a single action — for example, the −1 penalty for one normal move.

The total accumulated reward over an entire episode — the sum of every immediate reward from start to finish (or termination).

A value between 0 and 1 that controls how much the agent values future rewards versus immediate ones. A γ close to 1 makes the agent plan further ahead toward the target instead of only avoiding the very next penalty.

The expected return the agent can obtain starting from state s and then following its policy — how "good" a given maze cell is overall.

The expected return of taking a specific action a in state s, and then following the policy afterward. This is exactly what the application page displays as the "Q-values" table for each maze cell.

The algorithm used to learn Q(s,a) from experience, without needing a model of the environment. In this project it is implemented with a scikit-learn SGDRegressor per action, updated incrementally with partial_fit() every time the agent takes a step, instead of a plain lookup table.
