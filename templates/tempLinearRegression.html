Linear Regression: Application

Predicting gasoline consumption based on kilometers driven.

Problem Context

Vehicle fuel consumption tends to increase in a fairly predictable way as the distance traveled increases. This application uses Simple Linear Regression to estimate how many liters of gasoline a vehicle will consume for a given number of kilometers, based on historical consumption patterns. This kind of prediction can help drivers plan fuel budgets, estimate trip costs, and understand the relationship between distance and fuel usage.

Variables

Independent Variable (X)
Kilometers Driven

The distance traveled by the vehicle, measured in kilometers (km).

Dependent Variable (Y)
Gasoline Consumed

The estimated amount of fuel used, measured in liters (L).

Dataset Information

Number of records 500
Independent variable Kilometers Driven (km)
Dependent variable Gasoline Consumed (Liters)
Data source Simulated dataset generated based on the average fuel consumption rate of a standard passenger vehicle (approximately 0.12 liters per kilometer), with realistic random variation to reflect differences in driving conditions.
