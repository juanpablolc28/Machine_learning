Logistic Regression: Application

Predicting whether a team wins a match based on ball possession percentage, using a Binary Logistic Regression model trained with scikit-learn.

1. Problem Context

This application analyzes football/basketball match data to determine whether a team's ball possession is associated with winning the match. Each row of data represents one match, describing how much of the ball possession a team held and what the final outcome was.

  • Independent variable: Possession percentage (%) held by the team during the match.
  • Target variable: Match Result.
  • Class 0: Loss / Draw   Class 1: Win.
  • Goal: Classify a new match as a Win or a Loss/Draw based on possession percentage.

4. Train / Test Split

The dataset was split using scikit-learn's train_test_split(): 80% of the matches were used to train the model, and the remaining 20% were kept aside for testing (see the Evaluation Metrics page).
