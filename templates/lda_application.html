Linear Discriminant Analysis: Application

Predicting whether a team wins a match using four combined performance indicators, with a Linear Discriminant Analysis model trained with scikit-learn.

1. Problem Context

This application extends the match-outcome classification problem by combining several performance indicators instead of a single variable. Each row of data represents one match, describing its performance statistics and the final outcome.

  • Independent variables: Possession percentage (%), shots on target, average goals scored, and home advantage.
  • Target variable: Match Result.
  • Class 0: Loss / Draw   Class 1: Win.
  • Goal: Classify a new match as a Win or a Loss/Draw using all four variables together.

4. Train / Test Split

The dataset was split using scikit-learn's train_test_split(): 80% of the matches were used to train the model, and the remaining 20% were kept aside for testing (see the Evaluation Metrics page).

5. Model Pipeline
