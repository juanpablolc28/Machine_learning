## Types of Machine Learning

### Supervised Learning
The model is trained on labeled data, learning to map inputs to known outputs. Common tasks include classification and regression.

### Unsupervised Learning
The model works with unlabeled data, identifying patterns and structures on its own. Common tasks include clustering and dimensionality reduction.

### Semi-Supervised Learning
The model is trained on a combination of a small amount of labeled data and a large amount of unlabeled data.

### Reinforcement Learning
The model learns by interacting with an environment, receiving rewards or penalties based on its actions, in order to maximize cumulative reward.
